StellaViewer 0.2.0-preview.13

画像・書庫・PDFを閲覧する、Windows向けの無料画像ビューアです。
プレビュー版のため、未検証の環境やファイルでは正常に動作しない場合があります。

■ 動作条件
・Windows 11 x64（64ビット）
・.NET 10 Desktop Runtime x64（最新の修正版を推奨）
  Microsoft公式: https://dotnet.microsoft.com/ja-jp/download/dotnet/10.0
  「.NET デスクトップ ランタイム」のWindows x64を選択してください。
  通常の.NET RuntimeやASP.NET Core RuntimeだけではWPFアプリを起動できません。
・Visual Studio、MFCの開発環境、.NET SDKは通常の閲覧には不要です。
  Windows ARM64・32ビットWindowsはサポート対象外です。

■ 導入と更新
1. StellaViewer-0.2.0-preview.13-win-x64.zipを、書き込み可能な任意のフォルダへ
   すべて展開してください。ZIP内から直接起動しないでください。
2. 展開したStellaViewerフォルダのStellaViewer.exeを起動してください。
   EXEだけを取り出さず、DLL・licenses・説明書等を同じ配置で保持してください。
3. 更新時はStellaViewerをすべて終了し、新しい版を別フォルダへ展開して起動します。
   設定はアプリとは別の場所へ保存されます。更新前の設定のエクスポートを推奨します。

本版の実行ファイルにコード署名はありません。Windowsの保護機能が警告する場合は、
配布元とファイルを確認して判断してください。SHA256SUMS.txtで内容の変更も確認できます。

■ 基本操作
・ファイルメニューからフォルダ／ファイルを開くか、ウィンドウへドロップします。
・通常画像を指定すると、その画像の親フォルダも画像一覧へ開きます。
・左上のフォルダ・書庫一覧から、フォルダ、書庫、PDFを選択できます。
  一覧のシングルクリックは画像一覧へ開き、ダブルクリックは場所の一覧も移動します。
・画像領域のホイール下／上、または右／左キーで次／前の画像へ移動します。
・Ctrl＋ホイールで拡縮できます（設定で無効化可）。下部の倍率表示はクリックして
  数値入力できます。スライダーとリセットボタンも利用できます。
・拡大して表示領域を超えた画像は、初期設定では左ドラッグで移動できます。
・見開き、回転、グリッド、スライドショーは画像付近のバーやメニューから操作します。
・全画面は下部のボタンで切り替えます。全画面中のバーは画面端へマウスを寄せると表示します。
・F5で再読み込みします。操作の割り当ては「設定 → ショートカット」で変更できます。
・画像一覧の検索・表示形式・並べ替え、フォルダリンク、履歴、お気に入りも利用できます。

■ 対応形式と主な制限
・画像: JPEG、PNG／APNG、BMP、GIF、WebP。アニメーションは自動ループ再生です。
・PSD: RGB 8bit／16bitの合成画像、Raw／RLE圧縮に対応します。
  レイヤー個別表示、PSB、ZIP圧縮、その他のカラーモードは対象外です。
・CLIP: 保存済み画像を優先して表示します。縮小された保存画像の場合は通知します。
  CLIP STUDIO PAINTの全編集情報を再現する機能ではありません。
・書庫: ZIP／CBZ、7z、RAR／CBR。書庫内フォルダ・入れ子書庫・書庫内PDFを閲覧できます。
  TAR系は非対応です。暗号化・破損・特殊な形式等は開けない場合があります。
・PDF: 初期144 dpiで描画します。パスワード付きPDFは非対応です。
・1枚の表示用画素は原則256 MiBまで、アニメーションはデコード済みフレーム合計
  256 MiB／最大1,000フレームまでです。これはプロセス全体のメモリ上限ではありません。
  大きすぎる画像やアニメーションは、理由を通知して中止／静止表示へ切り替えます。
・入れ子書庫の一時展開は合計2 GiB・8段を暫定上限としています。
・PDFの100%は144 dpiで描画した画素の等倍です。印刷寸法の等倍ではありません。

■ ファイル操作
「送る」はコピーです。同名の場合は別名にし、通知します。コピー時は元の日時を引き継ぎます。
削除機能は初期状態で無効です。設定で有効にすると、確認のうえゴミ箱へ移動できます。
フォルダの削除は内容も対象です。通常ファイル／フォルダが対象で、書庫内項目やPDFページは
コピー・削除の対象外です。取り消せる条件はゴミ箱や保存先にも依存します。
大切なデータは別途バックアップしてください。

■ 設定と閲覧データ
設定・履歴・お気に入り・キャッシュ・一時展開データ等は、通常は次へ保存します。
  %LOCALAPPDATA%\StellaViewer
アプリを別フォルダへ移しても引き継がれます。履歴には閲覧先のパスが残ります。
「設定 → データと履歴」で履歴記録や閲覧位置保存の停止・削除、設定の
エクスポート／インポートができます。キャッシュは設定画面から確認・削除できます。
設定・配置・前回閲覧に加え、お気に入り・フォルダリンク・履歴も、破損時に
直前の正常なバックアップから復旧します。破損データは退避して通知します。
正常なバックアップもない場合は初期値へ戻るため、大切な登録は別途保管してください。
画像をクラウドへ送信する機能はありません。ネットワーク共有を閲覧する際は共有先と通信します。

■ 終了とアンインストール
すべてのStellaViewerを終了し、展開したアプリのフォルダを削除してください。
設定・履歴等も不要な場合に限り、上記のStellaViewerデータフォルダも削除します。
その場合はお気に入りやフォルダリンク等も失われます。元の閲覧ファイルは別のものです。
