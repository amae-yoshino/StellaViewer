# 導入・更新・削除

## 導入

1. Windows 11 x64と、Microsoft公式の[.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/ja-jp/download/dotnet/10.0)を用意します。
2. 配布元の `StellaViewer-0.2.0-preview.13-win-x64.zip` と `SHA256SUMS.txt` を取得します。
3. `Get-FileHash -Algorithm SHA256 <ZIPのパス>` と公開値を照合します。ハッシュ一致は内容の一致を確認するもので、配布者の本人性や安全性を単独で保証しません。
4. 新しいフォルダへ全体を展開し、`StellaViewer.exe` を起動します。EXEだけを取り出さないでください。

アプリは未署名です。警告を無条件に回避せず、配布元を確認してください。通常利用で管理者権限は不要です。

## 更新

アプリをすべて終了し、必要なら設定をエクスポートします。新しい版は別フォルダへ全体を展開し、そこから起動します。古いDLLが混在しないよう、既存フォルダへの上書き配置は避けてください。ショートカットも新しいEXEへ変更します。自動更新機能はありません。

設定・お気に入り・フォルダリンク・履歴・閲覧位置・キャッシュ等は `%LOCALAPPDATA%\StellaViewer` に保存します。アプリフォルダの変更でも引き継ぎます。旧版への設定互換性を保証していないため、ダウングレード前にはデータをバックアップしてください。

設定には閲覧パス、キャッシュには表示した画像の画素、一時領域には入れ子書庫やPDFのデータが残る場合があります。共有端末での取り扱いに注意し、設定画面から記録停止・履歴削除・キャッシュ削除を選べます。

## アンインストール

アプリ終了後、不要になった配布フォルダを利用者の判断で削除します。閲覧した元画像・書庫・PDFは別の場所にあり、配布フォルダの削除では削除されません。

設定等も不要な場合に限り、上記のデータフォルダを削除します。お気に入り等も失われるため、必要なデータを確認・保存してから行ってください。
